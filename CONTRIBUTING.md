# Contributing to the Elastic Copilot Cowork Plugin

Thank you for your interest in contributing! This guide covers the conventions
and workflows you need to know.

## What lives where

| Content       | Authored in                                                                                                                                                  | Notes                                                                                                            |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| Skills        | [`elastic/agent-skills-sandbox`](https://github.com/elastic/agent-skills-sandbox) → [`elastic/agent-skills`](https://github.com/elastic/agent-skills) → here | Synced automatically. **Do not edit files under `skills/`.**                                                     |
| App manifest  | This repo                                                                                                                                                    | `agentSkills` array in `appPackage/manifest.json` is auto-generated by CI; all other fields are hand-maintained. |
| Build scripts | This repo                                                                                                                                                    | Authored directly.                                                                                               |

## Getting started

```sh
# Clone and install
git clone git@github.com:elastic/copilot-cowork-plugin.git
cd copilot-cowork-plugin
npm install

# Run checks locally (same as CI)
npm run lint
npm test
atk validate --manifest-file ./appPackage/manifest.json

# Build and package the app
npm run package
```

## Making changes

1. Create a branch from `main` (use `origin` or a personal fork).
2. Make your changes.
3. Ensure `npm run lint`, `npm test`, and
   `atk validate --manifest-file ./appPackage/manifest.json`
   all pass.
4. Open a PR against `main`.

## Changelog

The changelog follows [keep-a-changelog](https://keepachangelog.com/) format.

CI auto-generates entries from PR titles into the `[Unreleased]` section.
Add the `skip-changelog` label if the change doesn't warrant one (e.g. CI config,
docs-only changes).
Adding this label _after_ a changelog commit is generated will revert that commit.

## Commit messages

Use `Assisted-by:` trailers for AI-assisted commits,
following the Linux kernel convention adopted at Elastic:

```
Add frobnicate hook for Kibana dashboards

Assisted-by: Claude Code <noreply@anthropic.com>
```

## Skills

Skills are **not authored in this repo**. The workflow is:

1. Draft in [`elastic/agent-skills-sandbox`](https://github.com/elastic/agent-skills-sandbox).
2. Promote to [`elastic/agent-skills`](https://github.com/elastic/agent-skills) once reviewed.
3. On each `agent-skills` release, skills are synced here automatically (once the
   `copilot-cowork` sync target in `agent-skills` is merged and its deploy token can
   reach this repo).

If you find a bug in a skill, file it upstream in
[`elastic/agent-skills`](https://github.com/elastic/agent-skills). Do not edit files
under `skills/` in this repo.

## Regenerating the skills list

If you need to manually regenerate the `agentSkills` array in `appPackage/manifest.json`:

```sh
npm run build
```

This requires Node.js 24+. CI also runs this automatically when `skills/` changes.
